- 云同步：新增"同步服务（数据库）"，与 S3/WebDAV 并行。数据按条同步，删除（取消收藏、删除浏览历史等）也会同步到其他设备，同一条目以较晚的修改为准。服务端是仓库 sync_server/ 中的 Cloudflare Worker 与 D1 数据库，需要自行部署，步骤见 wiki 的"同步服务部署"
- 云同步：E-Hentai 登录纳入同步（账号与属于账号的 Cookie），igneous 由每台设备自行获取；同步方式、启用同步与自动同步由每台设备各自决定，不再被其他设备的同步设置改回；设置项改名为"云同步设置"
- 云同步：选择同步类型时"同步设置"一项补上名称；WebDAV 远程路径以 / 结尾时不再产生 //；选择同步或导出项目的对话框在矮屏上可以滚动
- 实时超分：新增超分服务（仓库 sr_server/），在另一台有显卡的电脑上运行与桌面端相同的超分程序和模型，手机、平板与桌面端都可以通过它在阅读时超分页面，经 Tailscale 等内网访问。部署与设置见 wiki 的"实时超分"
- 关注页：翻过的画廊记为已读，下次出现时淡化显示；新增"关注页进度"，以时间轴显示读过与没读过的部分、上次停留的位置与书签，点封面即从那一本开始列出；长按卡片可以加入书签。详情页新增"关注位置"按钮，从这本画廊开始打开关注页；H@H 按钮移到操作栏最后
- 阅读器：手机和平板上，顶栏的定时翻页按钮换成锁定亮度：点一下按当前屏幕亮度锁定，再点一下交还给系统
- 历史记录：nhentai 记录的域名不在本机的 nhentai 域名列表中时，不再导致这一页及之后的历史全部加载不出来；E-Hentai 画廊更新为新版本后，打开新版本的详情页会沿用旧版本的阅读进度；多章节 JM 作品不再偶尔在历史页中漏显示
- wnacg：设置 → 高级中可以修改域名，改域名后旧域名上的历史与收藏仍能读出
- Komga：CBR、7z、PDF 等非 ZIP 格式的书也可以离线下载（按页下载）
