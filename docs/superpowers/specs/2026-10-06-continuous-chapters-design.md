# 阅读器跨章节连续滚动设计

日期：2026-10-06

## 1. 背景

多章节的 JM 本子与 Komga 系列在阅读器中以"兄弟书"连接：读到一章的结尾时出现"下一章"按钮，按下后阅读器关闭，再以下一章重新打开（`details_page_logic.dart` 的 `_openReader` 循环）。用户希望滚动阅读时，本章读完后下一章的页面直接接在后面，不必按按钮、不重新打开阅读器。

同时修正两处判定（同一分支）：

- 滚动布局中，最后一页至少一半在屏幕内即为读到结尾（原规则要求最后一页的末端在屏幕内）。
- "下一章"按钮与"本章读完"使用同一判定：最后一页为第一张可见图片时也算读到结尾。

## 2. 范围

- 适用于纵向、横向滚动布局。翻页与双页布局保持按钮切换。
- 适用于在线模式（JM 章节）与远程模式（Komga 书）的会话。已下载、归档、本地模式的会话保持按钮切换。
- 只向后接续。向前一章仍用顶部菜单的"上一章"，在会话内已载入时直接跳转，否则沿用重新打开。

## 3. 章节段

阅读会话由若干章节段组成：`ReadSegment(info, start, pageCount)`，`info` 为该章自己的 `ReadPageInfo`，`start` 为其第一页在整个列表中的序号。第一段即打开阅读器时的章节。`readPageInfo.pageCount` 表示整个列表的页数，随接续增加；各段的页数保存在段中。

接续一章时，状态中按页的列表（`thumbnails`、`images`、解析状态、错误信息、图片尺寸）在末尾追加该章的页数，已有序号不变，滚动位置不受影响。

### 3.1 按页的数据来源

- 页面链接：解析缩略图页时使用页所在段的 `galleryUrl` 与段内序号；JM 章节在 `ReadPageInfo.thumbnails` 中直接给出全部页面链接，不需请求。
- 图片：在线模式按段内页码解析图片页。JM 章节已下载的页面以本地文件预先填入 `images`，在线模式按文件显示；因此多章节 JM 本子的会话一律为在线模式，已下载的章节离线也能读。
- 远程模式：追加该书的 `images`。

## 4. 接续时机

滚动中最后一张可见图片距整个列表末尾不足 3 页时，用最后一段的 `loadSiblingBook(next: true)` 取下一章并追加。取到 null 表示没有下一章，不再尝试；取下一章失败时保留"下一章"按钮作为重试入口。同一时间只进行一次接续。

## 5. 当前章节

第一张可见图片所在的段为当前段。

- 顶部标题为当前段的标题；页码与滑块为段内页码与段页数；缩略图条下方的编号为段内页码。
- 读到结尾按当前段计算：当前段最后一页至少一半在屏幕内、或为第一张可见图片。
- "下一章"按钮在当前段读到结尾、且其后没有已载入的段时出现；按下时在滚动布局中接续并跳到新段开头，在其他布局中沿用重新打开。
- 当前段变化时，显示该章标题的提示，并调用新段的 `ReadPageInfo.onShown`（JM 用它记录正在读的章节与页数）。

## 6. 进度

每段有自己的进度刷新器（`ReadProgressFlushCoordinator`），写入该段的进度键并调用该段的远程上报（Komga）。

- 定时刷新与关闭阅读器时，写当前段的位置：读到结尾时为该段最后一页，否则为第一张可见图片的段内序号。
- 离开一段时立即写入它的最后位置。
- 关闭阅读器后，详情页若发现最后在阅读器中打开的章节不是当前显示的章节，就切换到该章节，阅读按钮显示该章的进度。

## 7. 验证

- 进度判定：最后一页过半、只露出一小部分、长图等情形。
- 阅读器端到端：打开两章的会话（页面为本地图片），在纵向滚动布局中滚到第一章末尾，第二章自动接上；第一章进度记为最后一页、第二章进度随滚动记录；标题与页码随当前段变化；`onShown` 依次调用。
