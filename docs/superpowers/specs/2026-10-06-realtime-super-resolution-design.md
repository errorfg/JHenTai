# 在线阅读时的实时超分设计（实验）

日期：2026-10-06
状态：实验版，仅桌面端（macOS、Windows、Linux），未发版

## 1. 背景与目标

现有的超分只能对已下载的画廊预先处理。目标是在线阅读时直接看到超分后的页面：每页下载完即在后台超分，完成后替换原图，不需要先下载整本。

可行性依据（M4 Max，800×1138 的页面，每页启动一次程序）：realesr-animevideov3 2 倍约 0.36 秒，realcugan 2 倍约 0.55 秒；阅读速度约每页 3–6 秒。模型与倍数由用户自行选择，基准测试用于在各台机器上取得数据。

## 2. 组成

| 部分 | 位置 | 说明 |
|---|---|---|
| 程序与模型清单、运行 | `lib/src/service/sr/sr_tools.dart` | `SrEngine`（realesrgan、realcugan 的 ncnn-vulkan 命令行程序及其发布包）、`SrModel`、`SrConfig`（模型 + 倍数 + 降噪）、`SrRunner`（不经 shell 启动，工作目录为程序所在目录） |
| 输入准备 | `sr_input.dart` | 解码任意格式、还原 JM 条带、编码为不带透明通道的 PNG；动图与宽度达到上限的页面不处理 |
| 实时服务 | `realtime_sr_service.dart` | 队列（一次运行一个，阅读位置之后最近的页面优先）、磁盘缓存（临时目录 `sr_cache`，上限 2 GB）、程序安装 |
| 基准测试 | `sr_benchmark.dart`、设置页的对话框 | 见第 5 节 |
| 阅读器 | `read_page_logic.dart`、`base_layout.dart` | 原图显示后请求超分；结果解码后替换；顶部菜单开关 |

与原有的"已下载画廊超分"（`super_resolution_service.dart`）互不影响，只共用 GPU 编号设置。

## 3. 输入为何统一转成 PNG

- 图片缓存文件没有扩展名，程序按扩展名选择解码器；JM 页面还需先还原条带。
- PNG 不能带透明通道：程序遇到透明通道会一并放大并强制输出 PNG，忽略指定的输出格式。因此从 RGBA 像素自行编码 RGB PNG（透明处按白底），压缩级别取最低，文件用后即删。
- 两个程序在 macOS 上不支持 BMP（解码失败），所以不用无压缩的 BMP。

## 4. 阅读器中的流程

1. 在线模式的页面原图显示完成时，调用 `requestRealtimeSr(index)`（每页一次）。
2. 服务按「模型|倍数|降噪|页面地址」的 MD5 查磁盘缓存，命中则直接返回；否则入队。
3. 运行完成后先用 `precacheImage` 解码，再把 `state.srImages[index]` 设为结果文件并刷新该页；页面改用文件显示，容器尺寸不变。
4. 关闭阅读器时清空等待中的任务，正在运行的一个做完并留在缓存。
5. 开关关闭时页面回到原图。

设置项（`SuperResolutionSetting`）：开关、模型、倍数、降噪等级、不处理的最小宽度（默认 1600，0 为不限）。程序目录：应用可执行文件旁有 `sr_tools` 文件夹时用它（实验包自带，免下载），否则为应用数据目录下的 `sr_tools`，可在设置页下载安装。

## 5. 基准测试

设置页「超分辨率 → 基准测试」。输入为页面图片所在的文件夹，或一个 JM 章节号：

- 文件夹：直接读取其中的图片，不联网。可执行文件旁有 `sr-benchmark-pages` 文件夹时默认填入。
- JM 章节：页面在开始时各下载一次，存入本次测试的文件夹，此后所有配置都读本地文件。

对每个配置（全部模型 × 倍数 × 降噪，共 21 个）：逐页各启动一次程序计时（与阅读时相同），再把全部页面放在一次运行里计时；后者的输出保留在 `out/<配置>/`，供肉眼比较。结果写入 `report.json` 与 `report.md`（系统、GPU 列表与所用编号、页面尺寸、每个配置的逐页耗时、首次运行耗时、单次运行的每页耗时、输出大小、失败原因），位于系统下载目录下的 `JHenTai-SR-Benchmark-<时间>`。

## 6. 验证

- 用真实的程序运行（`test/e2e/sr_e2e.json` 指定程序目录，缺省则跳过）：各模型按倍数输出；同一页只超分一次，之后读磁盘；JM 页面先还原；宽图与动图不处理；队列按阅读位置排序；基准测试产出报告并保留输出。
- 阅读器端到端：打开在线会话，等待后台超分，页面变为 2 倍的图；关闭开关后回到原图。
- 在线：真实 JM 章节的基准测试；从发布地址下载、解压并运行两个程序。
- 未在 Windows 与 Linux 上运行过；macOS 应用（沙盒）内启动下载的程序未验证。
